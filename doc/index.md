# OpenSTA documentation

OpenSTA is a gate-level static timing analyzer.

Use the navigation to browse the user guide, command reference, and
developer notes. Command, variable, and CLI pages are generated from a
built `sta` binary and are not checked in. Use `help <command>` in the
Tcl interpreter for the same command documentation that appears here.
